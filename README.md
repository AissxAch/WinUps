# 🚀 Windows Performance & Latency Optimizer Kit

A safe, modular, 1-click optimization toolkit for Windows 10 and Windows 11. Designed to reduce input latency, speed up system UI, unlock high-performance power plans, clean junk files, and optimize SSDs.

---

## ⚡ Quick Start (For You & Friends)

1. **Extract or open** this `WindowsOptimizer` folder.
2. **Right-click `RUN_OPTIMIZER.bat`** and click **Run as administrator** (or just double-click it; it will automatically request administrator permissions).
3. Follow the colorful on-screen steps. Once finished, restart your PC or log out to apply all changes.

---

## 🛠️ What This Optimizer Does

| Feature | Description | Benefit |
| :--- | :--- | :--- |
| **Instant Menus (`MenuShowDelay = 20ms`)** | Reduces Windows context menu delay from 400ms to 20ms. | Right-click menus and submenus appear instantly. |
| **Animation De-bloat** | Removes slow window minimize/maximize stutter. | Reduces load on integrated and dedicated GPUs. |
| **Instant Start Menu Search** | Disables Bing web search queries inside the Start Menu. | Local app/file search appears with zero network lag. |
| **Ultimate Performance Power Plan** | Unlocks & activates the hidden Windows Ultimate Performance scheme. | Eliminates CPU core parking latency and throttle drops. |
| **Windows Game Mode** | Ensures background tasks yield CPU threads to foreground games/apps. | Smoother frame rates and lower input lag. |
| **SSD TRIM Optimization** | Automatically detects all SSD drives and sends active TRIM re-optimization. | Restores peak SSD read/write speeds and lifespan. |
| **Junk & Crash Cache Cleanup** | Cleans orphaned temporary files and crash dumps. | Reclaims gigabytes of disk space safely. |
| **Network & DNS Tuning** | Flushes DNS cache, enables Receive-Side Scaling (RSS) and optimal TCP autotuning. | Lower latency and faster domain resolution. |
| **File Explorer Tweaks** | Shows file extensions and sets Explorer to open to 'This PC'. | Safer file browsing and faster navigation. |

---

## 🔄 100% Reversible (Undo Tool Included)

If you or your friend ever want to revert back to standard Windows defaults:
- Simply double-click **`UNDO_OPTIMIZER.bat`**.
- It will immediately restore Windows default animation speeds, search settings, and the Balanced power plan.

---

## 🛡️ Safety & Integrity
- **No broken system components**: Does not delete Windows Defender, Windows Update, or core system components.
- **No sketchy third-party executables**: Everything runs via native Windows PowerShell commands that anyone can inspect.
